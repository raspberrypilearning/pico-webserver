# Build a nonsense snack detector

In this step, you will make a snack detector that pretends to count scoops, buttons, and mysterious project ingredients.

The `Looks`{:class="block3looks"} category is mentioned here so the inline class syntax is used inside ordinary copy.

![A pretend snack detector](images/example.gif)

> [!INFO]
>
> **Snack signal** is the imaginary number your project uses when it decides that something interesting has happened.

> [!TIP]
>
> When you type an opening bracket, the code editor will automatically add a closing bracket.

> [!DEBUG]
>
> If your snack detector says everything is soup, check your variable names and punctuation carefully.

> [!ACCORDION] Downloading and installing the Raspberry Pi software
>
> Content here comes from the ingredient, but in this project it mostly reminds you to keep clicking buttons until something happens.

> [!TASK]
>
> Complete this step by making your project print a snack report.

```python filename="button_press.py" line_numbers="true" line_number_start="3" line_highlights="3,5-6"
snacks = ["raspberry", "scoop", "button"]

for snack in snacks:
    print("Detected: " + snack)

print("Snack report complete")
```
